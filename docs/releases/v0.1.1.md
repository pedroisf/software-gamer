## Correção de inicialização

Corrige a mensagem “Abra o Software Gamer normalmente, sem Executar como administrador” que impedia a abertura quando o Windows fornecia um token administrativo, inclusive herdado de outro processo. O aplicativo continua sem solicitar elevação e não bloqueia mais esse contexto. Ajustes de processos verificam o usuário e a sessão de destino. O instalador usa a recuperação corrigida ao substituir a versão 0.1.0.

## Avisos de atualização

- Verifica novas versões públicas no GitHub ao abrir e a cada 6 horas.
- Pergunta se deseja baixar; a confirmação abre a página oficial no navegador.
- Permite verificar manualmente ou desativar avisos em **Ferramentas e ajuda → Atualizações**.
- Não envia perfis, caminhos ou diagnósticos. O GitHub recebe IP e versão do app na conexão HTTPS.
- Não baixa, instala ou executa atualizações automaticamente. Ausência de internet não impede usar o aplicativo.
- A linha 0.x também oferece pré-releases de testes. O aviso é adiado enquanto a janela não está ativa.

**Quem usa 0.1.0 precisa baixar esta atualização manualmente uma vez.** O aviso de novas versões funciona a partir de 0.1.1.

## Arquivos

- `SoftwareGamer-Setup-x64.exe`: instalador para Windows 11 x64.
- `SoftwareGamer.exe`: executável portátil, com runtime incluído.
- `SoftwareGamer-win-x64.zip`: portátil, documentação e licenças.
- `SHA256SUMS.txt`: hashes dos três arquivos de distribuição.
- `SoftwareGamer-validacao-windows.zip`: resultados de testes, regressão de inicialização e capturas de interface.

O repositório e os downloads agora são públicos. A versão permanece uma pré-release sem assinatura digital comercial; homologação física e em jogos reais continua pendente. Consulte [as limitações](https://github.com/pedroisf/software-gamer/blob/v0.1.1/docs/LIMITACOES.md).
